# Online Learning Platform

A responsive and interactive **Online Learning Platform** developed using **HTML5, CSS3, and JavaScript** to provide a structured environment for managing courses, student enrollments, learning progress, payments, and certificates.

## Features

- Browse and search available courses
- View detailed course information
- Student enrollment functionality
- Student dashboard
- Track course learning progress
- View enrolled and completed courses
- Generate course completion certificates
- Admin dashboard
- Add, edit, delete, and manage courses
- Manage student enrollments
- Manage and monitor payment records
- Track payment and enrollment status
- Form validation
- Dynamic content rendering
- Responsive user interface
- Client-side data storage using Local Storage

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Concepts Used

**HTML5:** Semantic HTML, forms, structured layouts, navigation, and reusable page sections.

**CSS3:** Responsive design, Flexbox, Grid, media queries, animations, and user interface styling.

**JavaScript:** DOM manipulation, event handling, form validation, dynamic content rendering, application logic, and Local Storage.

## Student Module

The Student section allows users to:

Browse available courses
Search and filter courses
View course details
Enroll in courses
Track learning progress
View enrolled courses
View completed courses
Check payment status
Generate course completion certificates

## Admin Module

The Admin section provides centralized management of the platform, including:

Add new courses
Edit existing courses
Delete courses
Search courses
Manage student information
Manage enrollments
Monitor payment records
Track payment status

## Data Management

The project is developed as a front-end application and does not use a backend server or database.

JavaScript Local Storage is used for client-side data management, including:

Course information
Student enrollments
Learning progress
Payment status
Certificate-related information

## Responsive Design

The application is designed to work across different screen sizes using:

CSS Flexbox
CSS Grid
Media queries
Responsive navigation
Flexible layouts
Mobile-friendly components

## 1. Clone the Repository

git clone https://github.com/arpan0220/Online-Learning-Platform.git

## 2. Open the Project

Open the project folder in Visual Studio Code.

## 3. Run the Application

Open index.html using Live Server in Visual Studio Code.

The application will open in the default web browser.

You can also open index.html directly in a modern browser.

## Payment Functionality

The project includes a payment management section for demonstrating course payment records and payment status.

Note: Payment functionality is implemented for demonstration purposes only. The project does not process real financial transactions or use a real payment gateway.

## Certificate Generation

The platform provides certificate generation functionality for eligible completed courses.

Certificates are generated on the client side using JavaScript based on the student's course completion information.

## Limitations

This project currently does not include:

Backend server
MySQL/database integration
Real user authentication
Real payment gateway
Server-side security
Server-side data storage
Real-time communication

The application is intended as a front-end web development and portfolio project.
